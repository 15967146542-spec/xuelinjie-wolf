- 初始使用 CSS Grid 布局时，三个卡片出现竖向排列且无大小区分的问题。
- 改用 Flex 布局：
  - 调整 DOM 顺序为“亚军 → 冠军 → 季军”，利用 Flex 默认从左到右排列实现左中右布局。
  - 设置 `.top-three-grid { display: flex; justify-content: center; gap: 24px; }`。
  - 为冠军卡片设置 `flex: 1.4` 和 `margin-top: -12px`，使其更宽且略高于两侧，形成领奖台效果。
- 移动端适配：在 `@media (max-width: 768px)` 中改为纵向堆叠，取消冠军上移。

### 遇到的问题与解决
1. **前三甲卡片竖向排列**
   - **问题**：Grid 布局未能生效，导致三张卡片纵向堆叠，冠军未居中。
   - **解决**：改用 Flex 布局，调整卡片顺序，并利用 `flex` 属性控制宽度比例；确认无其他全局样式干扰。

2. **冠军卡片视觉不够突出**
   - **问题**：三张卡片大小相近，第一名不醒目。
   - **解决**：增大冠军头像至80px，添加金色阴影和上移效果，强化视觉焦点。
