# 学林街之狼

## 项目简介

“学林街之狼”是一个校园教学评价与模拟投资激励平台的前端原型。项目以行情看板的交互形式整合课程、教师与评价信息，通过任务、虚拟积分和排行榜提升学生参与度，并为教学管理提供评价审核与趋势查看入口。

项目服务于学生与教学管理者两类角色：学生可浏览课程标的、查看评价趋势、完成签到评教及模拟交易；管理者可审核评价、调整模拟参数并执行收盘结算。平台中的“股票”“交易”“资产”均为虚构标的和虚拟积分，仅用于教学互动演示，不涉及真实证券、支付、教师收入或投资建议。

## 技术与成果

前端采用 Vue 3、TypeScript、Vite、Pinia、Vue Router、Element Plus 与 ECharts 开发。当前已实现行情与详情、K 线和评教趋势、模拟交易与持仓、匿名评教、任务奖励、排行榜、个人中心及管理端等页面原型。业务数据暂由 Pinia 和 Mock 数据管理，为后续 API、权限和持久化接入预留了结构。
