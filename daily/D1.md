## 遇到的问题与解决

### 1. 原型所在目录被误删

**问题：** 前端原型最初在 `新建文件夹 (3)` 中完成，后因误操作删除，原始目录已无法直接读取。  
**解决：** 不再依赖被删除目录，而是检查当前项目文件、初始 Git 提交和构建结果，确认并保留可运行的原型基线；后续所有工作在课程 Gitee 仓库中按天提交，避免再次只保存在本地目录。

### 2. Windows PowerShell 直接执行 npm 受到执行策略影响

**问题：** PowerShell 可能拦截 `npm.ps1`，导致常规 `npm` 命令不能直接执行。  
**解决：** 使用 `npm.cmd install` 和 `npm.cmd run build` 执行依赖安装与构建，不修改系统执行策略。

### 3. README 中文内容出现编码损坏

**问题：** 原有 README 中文显示为乱码，不适合团队成员查看和后续协作。  
**解决：** 统一使用 UTF-8 编码维护项目文档；后续文档创建后先在编辑器中检查中文可读性，再进行提交。
