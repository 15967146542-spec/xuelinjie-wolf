遇到的问题与解决
1. 功能需求理解不清晰
问题： 初期对排行榜和管理端的具体功能需求理解不够明确。
解决： 通过阅读 README.md 和 立项报告.md，并与组长沟通，明确了功能需求和交互逻辑。

2. 状态管理结构设计复杂
问题： 排行榜和管理端的状态管理涉及多个字段，初期设计较为混乱。
解决： 参考其他模块的状态管理结构，简化字段定义，确保数据结构清晰。

3. Gitee 仓库创建后无法推送代码
问题： 初次推送代码时，提示权限不足或远程地址未设置。
解决： 确认 Gitee 仓库的 HTTPS 地址是否正确，并使用以下命令重新设置远程地址：

bash
git remote add origin https://gitee.com/username/xuelinjie-wolf.git


bash
git rm -r --cached node_modules
git add .gitignore
git commit -m "Add .gitignore"
git push origin main
git pull origin main
