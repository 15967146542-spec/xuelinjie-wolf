记录 5：整站白屏诊断与修复
================================================================

用户提示：
网站一片空白怎么解决。

诊断过程：
- dev 日志与模块 transform 均正常（HTTP 200），判断为浏览器运行时错误；
- 本机无浏览器工具，临时安装 playwright-core（--no-save）驱动系统 Chrome headless 抓 console：
  发现 [pageerror] createRouter is not defined，#app 内容为空 → 整站白屏根因。

  Vite/rolldown 不查类型、将其当全局引用编译，故 build 通过而浏览器抛 ReferenceError。
- 同类 merge 遗留：MarketView.vue 缺 MarketTab/MarketSortBy/SortOrder/TeacherStock 类型导入，
  StockDetailView.vue 缺 TradeSide（仅破坏类型检查，不白屏）。

修复（提交 2b17ed1，已推送 70fe162..2b17ed1）：
- src/router/index.ts：补 import { createRouter, createWebHistory } from 'vue-router'；
- src/views/MarketView.vue / StockDetailView.vue：补齐 @/types 类型导入。

验证：
- headless Chrome 扫描 10 个页面全部正常渲染、无 pageerror、标题正确、#app 已填充（body innerText>0）；
- vue-tsc 全量：Cannot find name/TS2304/TS2552 类错误清零（剩余仅 unused import 类噪音，属历史遗留）；
- npm run build ✓（885ms）。
