记录 1：项目初始化、仓库上传与协作 README
================================================================

用户提示：
把xuelinjie-wolf这个项目上传至 15967146542-spec/xuelinjie-wolf，并编写readme以便于我的4个组员进行接下来的开发。

与 AI 的协作过程：
1. 检查当前目录、package.json、README、路由、根组件和 Git 状态。
2. 发现项目目录尚未初始化为 Git 仓库；原 README 的中文编码损坏。
3. 读取现有 Vue 3 + TypeScript + Vite 工程配置，以及页面、store 和组件目录，确定协作边界。
4. 重写 README，补充环境要求、启动方式、构建命令、项目结构、功能概览、模块分工、分支与 Pull Request 约定。
5. 执行 npm.cmd run build 验证项目可以生产构建。
6. 初始化 Git 仓库，创建 main 分支和首个提交，推送到远程仓库。

执行结果：
- 项目完成 Git 初始化并成功推送。
- README 由乱码文本改为 UTF-8 中文协作文档。
- npm.cmd run build 构建成功。

学习与复盘：
- 提交前应先检查 Git 状态和远程地址，避免误推送。
- Windows PowerShell 受执行策略影响时，可使用 npm.cmd 代替 npm。
- 团队 README 不应只写启动命令，还应说明目录职责、协作边界和提交规范。

记录 2：立项文档与答辩 PPT
================================================================

用户提示：
写一份立项文档给我，后续我需要上交，并用这份文档生成ppt。

与 AI 的协作过程：
1. 从 TypeScript 类型定义和 Mock 数据中确认项目的业务对象、功能边界和技术方案。
2. 明确该项目是校园教学评价与模拟投资激励平台的前端原型，虚拟“股票”“交易”和“资产”不构成真实金融服务。
3. 编写项目立项书，包含背景与意义、项目目标、建设内容、技术方案、分工、实施计划、风险控制、验收标准和预期成果。
4. 安装 pptxgenjs，用脚本生成可编辑的 PowerPoint 文件。
5. 生成 11 页立项答辩 PPT，并检查 PPT 包内幻灯片数量。
6. 再次运行 npm.cmd run build，确认文档工作没有影响项目构建。

执行结果：
- 生成《学林街之狼项目立项书.md》。
- 生成《学林街之狼项目立项答辩PPT.pptx》。
- 生成 PPT 的脚本保存在 scripts/generate-proposal-ppt.mjs。
- PPT 共 11 页，项目构建成功。

学习与复盘：
- 立项文档必须先说明项目边界，尤其要区分模拟功能与真实金融业务。
- PPT 内容应与立项书保持一致，便于答辩时追溯依据。
- 使用脚本生成 PPT 可在分工、时间表或成果变动后快速更新演示材料。
