# D3 提示词记录（整理版，24320226）

> 本文为依据需求、代码范围和验收结果形成的整理版记录，不复用原始对话提示词。

## 任务背景
组长分工要求补齐公共体验层。移动端导航需要在窄屏下收纳入口，同时不丢失身份切换和资产概览。

## 任务拆解
1. 找出小屏下导航溢出的触发条件。
2. 增加汉堡菜单与抽屉式导航。
3. 把移动端必要操作放入抽屉，并保留键盘焦点提示。
4. 补足全局样式和减少动态效果偏好支持。

## 约束与取舍
- 桌面端维持原有导航；仅在窄屏切换为抽屉。
- 抽屉优先放置高频入口，避免页面内容被遮挡。
- 使用 focus-visible 而非永久高亮，兼顾键盘可访问性和视觉整洁。
- 增加 prefers-reduced-motion，减少不必要的动画。

## 核心追问
- 哪些入口必须在移动端首屏可达？
- 抽屉打开、关闭与焦点状态如何保持可理解？
- 全局样式改动是否会影响评教和课程页面？

## 验证清单
- 缩小视口后导航不溢出，汉堡菜单可打开与关闭。
- 身份切换和资产概览可在抽屉内访问。
- 焦点环、数字排版和减少动态效果偏好生效。
- npm run build（vite build）通过，并在 PR !8 中等待审查与测试。
