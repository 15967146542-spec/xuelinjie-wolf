## 遇到的问题与解决

### 1. `npm install` 反复失败 —— 根因是 npm 代理指向未运行的本地代理端口

**现象：** 从官方源与 npmmirror 安装均报 `ECONNREFUSED`，重试耗尽后 npm 自身崩溃（`Exit handler never called!`）。

**诊断（2026-09-02 补）：**
- `npm config get proxy / https-proxy` 均指向 `http://127.0.0.1:7890`（Clash/v2rayN 类代理默认端口）；
- TCP 探测 `127.0.0.1:7890` 返回 `ECONNREFUSED`，即该代理软件当前未运行；
- 与此同时 Node `fetch` 直连 `registry.npmjs.org`、npmmirror、gitee 全部 200，`registry.npmjs.org:443` 端口 OPEN —— **外网本身通畅**；
- 结论：npm 全量流量都走了死代理端口导致失败，并非网络故障。

**解决：** 执行 `npm config delete proxy` 与 `npm config delete https-proxy` 后直连官方源，`npm install` 12s 完成（68 packages）。
